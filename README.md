## Developer Philosophy

- **Ship systems that age well**: predictable patterns, clean contracts, and minimal surprises.
- **Make the data model do the heavy lifting**: schema clarity > clever code.
- **Optimize for reliability**: observability, validation, and safe defaults.
- **Build like it will scale**: even small projects benefit from strong foundations.

<br/>

## Architecture Mindset

I approach engineering like a backend architect:

- **Boundaries**: separation of concerns, modular services, and clean layering.
- **Performance**: caching strategies, DB indexing awareness, and efficient queries.
- **Scalability**: stateless services, queue-friendly design, and horizontal thinking.
- **Security**: auth flows, input validation, least privilege, and secure data access.
